Hangman Game

Internship Project 1

A terminal-based Hangman game developed using Python.

Project Description

Hangman is a word-guessing game where the player attempts to guess a randomly selected hidden word one letter at a time.

The player is allowed six incorrect guesses before the game ends.

Features

- Random word selection
- Six incorrect guesses allowed
- ASCII gallows animation
- Displays correctly guessed letters
- Tracks previously guessed letters
- Prevents duplicate penalty deduction
- Detects winning and losing conditions

Technologies Used

- Python 3
- Random module
- VS Code

How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the following command:

python hangman.py
